# Rank Thing API v1 Documentation

## Base URL
```
http://localhost:3000/api/v1
```

Replace `localhost:3000` with your server's host and port.

## Authentication
No authentication required for v1.

## Content-Type
All requests must include:
```
Content-Type: application/json
Accept: application/json
```

---

## Response Format

### Success
```json
{
  "success": true,
  "data": { ... },
  "message": "optional message"
}
```

### Error
```json
{
  "success": false,
  "error": "error_type",
  "message": "Human readable error message"
}
```

### HTTP Status Codes
| Code | Meaning |
|------|---------|
| 200 | OK - request succeeded |
| 201 | Created - resource created successfully |
| 400 | Bad Request - invalid parameters |
| 404 | Not Found - resource doesn't exist |
| 422 | Unprocessable Entity - validation failed |
| 500 | Internal Server Error |

## TUI Implementation Notes

### Ranking Algorithm
- Rankings use the Elo rating system
- Default ranking for new items: 1200
- K-factor: 32
- Higher numbers = better rank

### Compare Endpoint
- Returns 2 random items from the category
- Order is randomized (not sorted by ranking)
- Call vote endpoint after user makes selection

### Bar Width Calculation (for charts)
```go
// Example Go code for calculating bar width
func calcBarWidth(ranking, minRank, maxRank float64) int {
    if maxRank == minRank {
        return 50 // default width when all equal
    }
    range := maxRank - minRank
    return int(((ranking - minRank) / range) * 100)
}
```
